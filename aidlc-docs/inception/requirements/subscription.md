## 배경 — 결정 시점의 현황

- **비용 거버넌스는 이미 사용자 단위로 작동한다**: `CostGuardCircuitBreaker` 공유 포트(U6 구현), 에이전트 Bedrock 경로 실측 spend 기록, per-user daily 쿼터(evidence 30/day · novelty 5/day — Redis 공유, fail-open). 구독제는 이 집행 메커니즘에 **플랜별 쿼터 값을 공급**하는 방식으로 얹힌다(CostGuard 계약 불변).
- **계정에는 플랜 개념이 없다**: `UserRole = USER | ADMIN` 뿐 — 플랜은 신규 도메인(U16), 인증 도메인(U3)과 분리.
- **시대 맥락**: 개인 포크·로컬 mac-mini 서빙 — 실결제(PG 심사·사업자·세무)는 제품 밖 부담이라 **v1에서 결제를 카브아웃**(OQ-1=b)하고 티어 도메인만 먼저 굳힌다. 결제 도입은 추후 어댑터 추가 경로.
